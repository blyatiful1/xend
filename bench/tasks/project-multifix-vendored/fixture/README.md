# kit

A grab bag of utility modules used across our services: text wrapping (`kit.wrap`), diffs (`kit.diffs`),
statistics (`kit.stats`), exact fractions (`kit.ratio`), shell-style lexing (`kit.lexer`), calendars
(`kit.cal`), IP address handling (`kit.netaddr`) and INI configuration (`kit.config`).

Run the tests with `python3 -m pytest -q tests`.
