# kit

A grab bag of utility modules used across our services: `kit.wrap`, `kit.dec`, `kit.diffs`, `kit.urls`, `kit.stats`, `kit.cli`, `kit.ratio`, `kit.pretty`, `kit.lexer`, `kit.plist`, `kit.cal`, `kit.globs`, `kit.netaddr`, `kit.heap`, `kit.config`, `kit.graph`.

Run the tests with `python3 -m pytest -q tests`.
